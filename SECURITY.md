# Security / Безопасность

## Reporting a problem

If you find a security problem — for example, **redacted data can still be found, copied or recovered**, a document leaks data it should not, or the update mechanism behaves unexpectedly — please **do not open a public issue**.

Write to **support@constructpdf.ru** with the subject `Security`. Include the program version, your OS, the steps to reproduce and, if possible, an anonymized example file. Do not send documents with real personal data.

Every report will be reviewed. Confirmed and fixed problems will be noted in the release notes.

## Supported versions

Only the latest release receives fixes. The program checks for updates and offers to install a new version.

---

## Как сообщить о проблеме

Если вы нашли проблему безопасности — например, **закрашенные данные всё равно находятся поиском, копируются или восстанавливаются**, документ раскрывает лишние данные или обновление ведёт себя неожиданно, — пожалуйста, **не создавайте открытый issue**.

Напишите на **support@constructpdf.ru** с темой `Security`. Укажите версию программы, систему, шаги для воспроизведения и, если можно, обезличенный пример файла. Не отправляйте документы с реальными персональными данными.

Мы рассмотрим сообщение. Подтверждённые и исправленные проблемы будут отмечены в описании релиза.

## Поддерживаемые версии

Исправления выходят только для последней версии. Программа сама проверяет обновления и предлагает установить новую.
